# Domain Research Workflow

Use this workflow after selecting a profile under `profiles/`.

## 1. Classify the question
Identify domain, required freshness, evidence class, and whether one or multiple notebooks are needed.

## 2. Select sources
Prefer the strongest evidence bucket defined by the profile. Do not query a community/practitioner notebook as if it were clinical, scientific, regulatory or canonical product documentation.

## 3. Query
Use the root `workflows/ask.md` mechanics for each relevant notebook. Phrase queries to request claims, conditions, counterevidence and citations.

## 4. Triangulate
When a material decision depends on the answer, query at least one independent/opposing source bucket where available. Preserve contradictions.

## 5. Freshness gate
For AI, AI-video, investing/current markets, regulation, or other changing facts: if the question asks what is true now, verify with current primary sources outside the static NotebookLM corpus before presenting it as current.

## 6. Synthesize
Follow the selected profile's default answer contract. Keep source type and date visible. Distinguish fact, evidence, expert interpretation and anecdote.

## 7. Save
Optionally use the root citation resolver/import workflow to persist the cited Q&A in Obsidian.
