# AI Video Lab

## Mission
Turn creator tutorials, official documentation and experiments into reproducible video-generation workflows.

## Tools/topics
Higgsfield, Seedance, Veo, Kling, Runway and other relevant systems; image-to-video; video-to-video; reference assets; character consistency; lip sync; camera movement; prompt engineering; editing and compositing.

## Freshness
Capabilities change rapidly. Attach model/version/date to advice. For current feature availability or UI steps, verify against current official material rather than relying on an older transcript.

## Default workflow answer
Goal -> recommended technique -> asset requirements -> model/version -> minimal prompt -> settings/shot constraints -> iteration strategy -> failure modes -> fallback -> cited examples.

Prefer minimal executable prompts over bloated prompts when the model/tool performs better that way. Separate documented capability from creator workaround.

For transformation tasks, explicitly define what must remain invariant (identity, framing, motion, timing, camera) and what may change.
