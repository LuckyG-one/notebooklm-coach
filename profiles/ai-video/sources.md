# AI Video source plan

Suggested notebooks:
1. **Official Docs & Releases** — current model docs, release demos, changelogs.
2. **Creator Workflows** — high-signal tutorials and experiments.
3. **Cinematic Craft** — camera language, editing, lighting and storytelling that transfer across models.
4. **Tool-specific notebooks** when a corpus becomes large (Higgsfield, Seedance, Veo, Kling, Runway).

Tag every workflow with tool/model/version/date so obsolete techniques are easy to spot.
